MORNING CIRCUIT - GITHUB PAGES

1. Extract this ZIP to a folder.
2. Create a PUBLIC GitHub repository called morning-circuit.
3. Upload the EXTRACTED files/folders to the repo root. Keep index.html in the top level.
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Visit https://YOUR-USERNAME.github.io/morning-circuit/
6. On iPhone: Safari > Share > Add to Home Screen.
   On Android: Chrome menu > Add to Home screen / Install app.

The site uses simple hand-coded SVG illustrations and CSS; no generated images or external scripts.
Progress saves in your browser, independently per device, and resets each day.
